Riley Mitchell • IDM241

CONTROL CENTER BUTTON

TRIGGERS

Control Center

  • Hover on/off the Control Center trigger.
  • Click (collapsed) — Collapsed → Expanded.
  • Click (expanded) — Expanded → Collapsed.

Ringer

  • Hover on/off the button.
  • First click — Ringer ON → Ringer OFF.
  • Second click — Ringer OFF → Ringer ON.

Light / Dark

  • Hover on/off the button.
  • First click — Light Mode → Dark Mode (sun hides, moon shows).
  • Second click — Dark Mode → Light Mode (moon hides, sun shows).

Low Power Mode

  • Hover on/off the button.
  • First click — Low Power OFF → Low Power ON.
  • Second click — Low Power ON → Low Power OFF.

Screen Orientation Lock

  • Hover on/off the button.
  • First click — Orientation UNLOCKED → LOCKED.
  • Second click — Orientation LOCKED → UNLOCKED.

RULES

Control Center

  • Hover:
    • Pointer cursor indicates clickable trigger.
  • Click (collapsed → expanded):
    • Set Control Center state to expanded.
    • Trigger widens horizontally, then stretches vertically.
    • Child buttons become visible in a vertical stack.
    • Each child button keeps its own previous toggle state.
  • Click (expanded → collapsed):
    • Set Control Center state to collapsed.
    • Panel scales closed; trigger returns to compact circle.
    • Child buttons are hidden but states are preserved.

Ringer

  • Hover:
    • Pointer cursor appears over the ringer button.
  • Click (ON → OFF):
    • Set ringer state to OFF.
    • Background changes from dark green/grey to white.
    • Bell icon switches from white to red.
    • Diagonal slash animates in across the bell.
  • Click (OFF → ON):
    • Set ringer state to ON.
    • Background changes back to dark green/grey.
    • Bell icon switches from red back to white.
    • Diagonal slash retracts/erases.

Light / Dark

  • Hover:
    • Pointer cursor appears over the appearance button.
  • Click (Light → Dark):
    • Set appearance state to Dark.
    • Outer circle changes from green/grey to white.
    • Inner circle changes from white to black.
    • Sun icon rotates/scales out; moon icon rotates/scales in.
  • Click (Dark → Light):
    • Set appearance state to Light.
    • Outer circle changes back to green/grey.
    • Inner circle changes back to white.
    • Moon icon rotates/scales out; sun icon rotates/scales in.

Low Power Mode

  • Hover:
    • Pointer cursor appears over the Low Power button.
  • Click (OFF → ON):
    • Set Low Power state to ON.
    • Outer circle changes from dark green/grey to white.
    • Battery outline and tip change to yellow.
    • Fill bar animates wider, then settles to a slightly shorter yellow bar.
  • Click (ON → OFF):
    • Set Low Power state to OFF.
    • Outer circle returns to dark green/grey.
    • Battery outline and tip change back to light/white.
    • Fill bar shrinks back to the shorter, neutral bar.

Screen Orientation Lock

  • Hover:
    • Pointer cursor appears over the orientation button.
  • Click (UNLOCKED → LOCKED):
    • Set orientation state to LOCKED.
    • Button background transitions from green/grey to white.
    • Phone border and lock switch to red/light red.
    • Phone briefly tilts/rotates, then bounces back upright with a closed lock.
  • Click (LOCKED → UNLOCKED):
    • Set orientation state to UNLOCKED.
    • Phone and lock icon rotate fully inside the circle.
    • Lock switches to unlocked icon.
    • Background fades back to green/grey; phone/lock revert to white.

FEEDBACK

Control Center

  • Hover:
    • Pointer cursor indicates the trigger is clickable.
  • Expand:
    • Trigger morphs from a circle to a pill and then reveals the vertical panel.
    • Four child buttons slide into view inside the panel.
  • Collapse:
    • Panel scales closed; child buttons disappear behind the top trigger.
    • Trigger returns to circular control.

Ringer

  • Hover:
    • Pointer cursor on hover.
  • Ringer ON → OFF:
    • Button slightly grows then eases back to normal size.
    • Background switches from dark green/grey to white.
    • Bell icon turns red.
    • Diagonal slash animates across the bell.
    • Bell shakes briefly.
  • Ringer OFF → ON:
    • Button slightly grows then eases back to normal size.
    • Background returns to dark green/grey.
    • Bell icon turns white again.
    • Diagonal slash erases out.
    • Bell shakes briefly.

Light / Dark

  • Hover:
    • Pointer cursor on hover.
  • Light → Dark:
    • Outer circle flashes to white; inner circle turns black.
    • Sun image spins/scales out of view.
    • Moon icon spins/scales into the center.
  • Dark → Light:
    • Outer circle fades to green/grey; inner circle returns to white.
    • Moon spins/scales out of view.
    • Sun spins/scales back into view.

Low Power Mode

  • Hover:
    • Pointer cursor on hover.
  • OFF → ON:
    • Outer circle brightens to white.
    • Battery outline and tip turn yellow.
    • Fill bar quickly expands, then eases back to a shorter yellow bar.
    • Small “spark” animations appear around the battery edges.
  • ON → OFF:
    • Outer circle darkens back to green/grey.
    • Battery colors return to neutral white/grey.
    • Fill bar shrinks back to the smaller bar length.

Screen Orientation Lock

  • Hover:
    • Pointer cursor on hover.
  • UNLOCKED → LOCKED:
    • Button background brightens to white.
    • Phone border and lock icon shift to red tones.
    • Phone tilts and bounces back with a closed lock icon centered.
  • LOCKED → UNLOCKED:
    • Phone + lock spin around inside the circle.
    • Lock switches to the unlocked icon.
    • Button fades back to green/grey with white phone/lock.
